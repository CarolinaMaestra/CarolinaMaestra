# 🌿 Carolina Ramírez Silva — Currículum Vitae Web

Sitio web personal tipo currículum vitae de **Carolina Ramírez Silva**, maestra de educación primaria con más de 20 años de trayectoria docente en Jalisco, México.

🔗 **Ver sitio en vivo:** `https://TU-USUARIO.github.io/TU-REPOSITORIO/`

---

## 📋 Contenido del sitio

- **Inicio** — Presentación con foto, nombre y datos de contacto
- **Sobre mí** — Perfil profesional y estadísticas de trayectoria
- **Experiencia** — Línea de tiempo con historial laboral
- **Educación** — Formación académica (licenciaturas y maestría)
- **Habilidades** — Competencias profesionales y personales
- **Contacto** — Correos y teléfono de contacto
